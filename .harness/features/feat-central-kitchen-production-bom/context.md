# 特性背景：生产 BOM 中心与版本生命周期管理 (feat-central-kitchen-production-bom)

## 一、 业务目标与需求背景

中央厨房生产 BOM 是制造与加工业务的核心中枢。本特性承担第一版生产 BOM 的列表管理与完整 CRUD 功能落地。

### 业务核心认知 (基于《中央厨房ERP第一版业务闭环与业务设计.md》)
1. **统一物料主档**：原料、半成品、成品、包材共用 Product 模型，通过 `product_kind` 区分；
2. **BOM 族 vs BOM 版本 (双身份)**：
   - `bom.id`: 稳定版本族身份（方案容器）；
   - `bom_version.id`: 不可变生产方案完整定义快照；
3. **三种 BOM 类型统一模型**：
   - 单品加工 (`PROCESSING`)：主原料加工为成品（如 青椒 -> 青椒段）；
   - 组合配方 (`FORMULA`)：多原料组合为成品（如 肉片 + 淀粉 -> 腌制肉）；
   - 包装装配 (`PACKAGING`)：散装物料 + 包材 -> 包装商品（如 65g青椒段 + 包装袋 -> 1包）；
4. **扁平化生产定义 (三大清单)**：
   - 投入清单 (`bom_version_input`): 用什么、用多少；
   - 产出清单 (`bom_version_output`): 产什么、产多少（`PRIMARY` 唯一主产出即 BOM 商品）；
   - 工艺清单 (`bom_version_operation`): 需要哪些工序及加工顺序。
5. **隔离与独立性**：
   虽然上游商品中心、仓储中心、工艺中心正在并行开发，但 BOM 切片自包含列表管理、筛选、增删改查、试算模型与版本生命周期。
