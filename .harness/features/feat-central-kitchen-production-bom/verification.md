# 验证用例与验收证据 — feat-central-kitchen-production-bom

## 验收检查清单与真实证据

1. **BOM 列表查询与观麦高保真交互**:
   - 顶部切签：支持 全部 / 单品 (`PROCESSING`) / 组合 (`FORMULA`) / 包装 (`PACKAGING`) 快速过滤；
   - 筛选管道：支持商品分类联动筛选、BOM 名称与编码关键字搜索；
   - 列表呈现：对齐观麦序号、默认 Badge、BOM 名称、BOM 编码、生产产线、商品名称与编码、分类、类型、工序标签列表与行操作栏；
   - 行操作栏：支持 详情、编辑、设为默认、二次确认删除。

2. **BOM 新增/编辑 (BomEditorModal)**:
   - 单品/组合/包装类型切换；
   - 投入清单交互：支持原料商品选择、数量/配方占比输入、单位带出、熟出成率配置；
   - 产出清单交互：主产出商品自动对齐与单位联动；
   - 工艺工序交互：工序路线增删行、顺序号、标准工时、质检点配置；
   - 总出成率开关控制与商品默认 BOM 快捷开关。

3. **BOM 详情与版本流程图谱 (BomDetailDrawer)**:
   - 顶部商品徽标卡片与版本历史下拉切换；
   - 高保真还原观麦可视化流程图谱：原料投入节点 -> 加工工序链菱形节点 -> 最终产出成品卡片；
   - 投入清单、产出清单、工艺路线明细 Tab 切换。

4. **架构合规与全栈门禁 (100% PASS)**:
   - `pnpm check`: 24/24 包类型检查 100% 通过；
   - `pnpm test`: 21/21 测试套件 390+ 单元测试 100% 通过；
   - `node scripts/verify.mjs`: 15 项架构门禁全绿通过。
