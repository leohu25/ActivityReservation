# 特性背景：生产资源与工艺主数据 (feat-central-kitchen-production-resources)

## 一、 业务目标与需求背景

实现中央厨房生产资源与工艺档案管理，重点落地“工艺规格档案维护”核心业务：
1. **外列表（工艺档案列表）**：
   - 以工序 (Operation) 为核心主档，直观展示工序编码、工序名称、工序分类、准备/清理耗时、参考出成率、最小批量与单位、工艺规格数量、状态等；
   - 具备快速关键字搜索、分类筛选、状态过滤、导出、启停用与软删除。
2. **编辑/新建页（主-子技术表单，上半部分技术信息 + 下半部分工艺规格明细表）**：
   - 上半部分：维护工序主技术信息（编码、名称、分类、出成率、准备时间、清理时间、最少人数、最小批量及单位、SOP说明、状态）；
   - 下半部分：对应明细表，可动态添加/删除/编辑多个工艺规格（ProcessingSpecification：编码、名称、出成率、加工说明/工艺要求、状态）；
   - 提交时整体事务原子性保存主表与子表规格。
